# 提问式论文写作工作流

> 不会写论文没关系，全世界论文水平下降一万倍，而我保持不变。这个工作流来拯救你了。

## 没思路也能开始写论文

**你负责回答你知道的，剩下的我们一起想办法。**

这是一套让 Claude 用**提问式（苏格拉底式）**陪你写课程论文的流程，由两篇真实的课程论文熬出来：

- 一篇调研案例型（有实地观察、照片、评论等一手材料）
- 一篇文献综述型（靠文献之间的结论冲突找研究问题）

"剩下的"也有边界：Claude 可以给你方向、帮你找资料、起草文字，但**不编造文献、数据、调查结果，也不替你编观点**。观点和判断永远是你的。

## 两种用法，不用你选

| | 🌱 引导：没思路 | ⚡ 高效：没时间 |
| --- | --- | --- |
| 怎么问你 | 每轮 1 到 2 个，从具体好答的问起 | 最多 3 到 5 个，已知的不问 |
| Claude 做多少 | 你说一步，它走一步 | 它先起草，不中途打断你 |
| 关键节点 | 小结，请你确认 | 最后给一张 3 到 5 条的确认清单 |

你不用一开始就选。Claude 会听你怎么说话，分开判断两件事：**时间**够不够，**思路**有没有。

- 有思路 + 时间紧：快速推进，少提问
- 没思路 + 时间够：一步步问，帮你理解
- 没思路 + 时间紧：少提问，但每个问题附一句简短解释和 2 到 3 个候选方向，让你快速拍板
- 都看不出来：从一个简单问题开始，不让你选模式

判断完它会告诉你一句。你说"快一点"或"慢慢聊"，它优先照你说的来。**切换不会丢掉你已经确认的观点、资料和进度。**

回答"不知道"也没关系：它会先给你 2 到 3 个容易懂的方向选，实在看不懂再补背景和例子，不会一上来长篇讲解。

**不管哪种节奏，这些都不省：** 文献逐条核实、事实核对、老师式通读。

## 怎么用

**方法一：不装，直接用（最简单）**

1. 打开 `socratic-paper-writing/SKILL.md`，复制全文。
2. 新开一个 Claude 对话，粘贴进去，再补一句：
   > 照这个流程带我写论文。我先把课程要求发给你。
3. 把老师的通知、课件照片发给它（课程要求交封面的话，再加上封面模板），然后跟着它走。

**方法二：保存成 Claude 技能**

1. 把技能文件夹 `socratic-paper-writing`（里面是 `SKILL.md`）压缩成 ZIP。注意压缩包打开后第一层必须是 `socratic-paper-writing` 这个文件夹，不能直接是 `SKILL.md`。
2. 在 Claude 的设置（Settings → Capabilities）里开启"代码执行和文件创建"，这是使用技能的前提。
3. 进入 Customize → Skills，点"+"→ Create skill → Upload，上传 ZIP 并启用。

界面可能会更新，具体以 Claude 当前界面和官方说明为准。启用后只要说"帮我写论文""我没思路"，它就会按流程来。

**注意：** 技能里提到的保存文件、项目记忆等功能，取决于你用的环境是否支持。不支持时，技能要求 Claude 输出一份可复制的进度记录让你自己保存，而不是声称"已保存"。联网检索、生成 Word 也一样，环境不支持时需要你自己贴摘要、自己排版。

## 第一句话怎么说

口语就行：

- 没思路："我不太会写论文，你一步一步问我，我来回答。"
- 没时间："我赶时间，你问我几个关键的，其余你先起草。"
- 通用："这是老师的通知和课件照片，帮我整理成：交什么、什么时候交、评分要求。有不懂的直接问我，不要猜。"

## 实际是这样的

**🌱 引导**

> **你：** 我想写一篇关于共享单车的论文，但不知道写什么。
>
> **Claude：** 我先按慢一点、一步步问你的节奏来，想快一点说一声就行。第一个问题很小：你平时骑共享单车吗？最让你印象深的一个场景是什么？
>
> **你：** 地铁口的单车堆得到处都是，老人过马路很难。
>
> **Claude：** 这个场景可以直接写进正文。接下来有两个方向，你选一个更有感觉的：A. 乱停放对老人出行的影响；B. 哪些时间、哪些路口最严重。
>
> **你：** A。

**⚡ 高效**

> **你：** 我赶时间。课程要求和 8 篇文献摘要都在这了，主题是短视频对大学生睡眠的影响，你先起草。
>
> **Claude：** 好，我按快一点的节奏来：已有资料能确认的我先做，不打断你。动笔前只需要你定一件事，也就是研究问题的方向：你想重点写"刷多久才算影响睡眠"，还是"为什么明知影响还停不下来"？
>
> **你：** 第二个。
>
> **Claude：** 那研究问题我先写成"大学生睡前刷短视频停不下来的原因有哪些"，你看可以吗？可以我就开始起草。
>
> **你：** 可以。
>
> **Claude：** （起草大纲和各节草稿，没证据的地方标【待补】。）最后请你确认 4 件事：研究问题的最终写法、某一类文献的缺陷表述、两处【待补】、以及你是否同意"宿舍作息可能是原因之一"这个推测。

## 哪些测试过，哪些还没

**已经实际用过**（是在 Claude 的项目环境里用的，可以保存文件、联网检索；"上传技能后在普通对话里用"这种方式还没完整试过）**：**

- 🌱 引导式提问：整篇调研案例型论文，从选题到定稿。
- ⚡ 高效式（Claude 起草、用户改写）：一篇综述型论文用过一次。
- 十步流程、文献逐条核实、老师式通读、Word 排版：两篇论文都用过。

**新增，还没验证：**

- 自动判断用户该慢还是该快（分别看时间和思路两个维度）。
- 文献检索由 Claude 自主批量完成、按重要性分级核实，以及"批量集中求助"的做法。
- 用户能不能分清 ✅（文献信息已核对）和"摘要级 / 全文级"（观点核实到哪一层）。清单开头固定放一句说明，试用时看有没有人误以为 ✅（摘要级）就是完全核实。
- 写作中途切换节奏，并且不丢进度。
- "不知道时先给 2 到 3 个方向"的做法。
- ☑️ 和 ⚠️ 标记、"候选清单和最终参考文献表分开"、提交前清单这几条定稿门槛。
- 环境不能保存文件时，改为输出进度记录让你自己保存的退路。

所以请当它是个人用法分享，不保证适合所有学科和老师的要求。如果你试用了，欢迎告诉我们：**从你说出写作需求，到拿到一份自己认可的大纲，一共回答了多少个问题？**

## 流程概览（10 步，两种节奏共用）

1. **读要求**：交什么、何时交、格式、文献数量、内容侧重。
2. **判断类型**：调研案例型，还是文献综述型。
3. **找文献并核实**：环境能联网时，Claude 自己批量检索、去重、核实（不能联网就请你贴摘要），按重要性分三级：核心文献深度核实，辅助文献查不到就换，低相关直接排除。元数据（作者、年份、期刊等）和内容（只看过摘要就标"摘要级"）分开核。知网等付费库的全文它常常打不开，这类会**批量集中请你帮忙**，不逐篇麻烦你；出现新的关键缺口时才会再请求。
4. **定研究问题和论证骨架**：有思路你自己写，Claude 只找逻辑漏洞；没思路 Claude 给 2 到 3 个候选，你选、你改、你定。
5. **提问式搭大纲**：把你的回答变成"每步一句话"。
6. **整理一手材料**：照片、评论、亲身经历，写明能证明什么、不能证明什么。
7. **分块成稿**：小块给草稿，你改成自己的话，Claude 再查事实。引导节奏按章节逐步确认；高效节奏连续起草，最后集中确认。
8. **老师式通读**：Claude 从逻辑、事实、格式挑毛病，你逐条决定改不改。
9. **排版成 Word**：按目标期刊或通行格式，核对引用编号。
10. **定稿前**：通读、最后核对（不能再有【待补】，没核实完的文献不进最终参考文献表；关键证据还缺、或有观点没经你确认时，Claude 不能说"可以提交"）、确认学校对 AI 协助写作的规定。

## 几条最管用的规矩

- 永远写完整题名，别只写"某某等"。
- 区分三类句子：事实和数据必须核实（查不到就删，或标【待补】）；分析推论可以提，但要说明依据和不确定性；你的观点保留原意，写明证据范围。
- 版本要说清以哪版为准，改稿只动该动的地方。
- 写完文件要重读验证。

## 🔒 隐私说明

这个仓库里只有文字说明，没有任何程序代码，技能本身不会收集数据，作者看不到任何使用者的对话和文件。使用时 Claude 可能会联网检索文献，这是 Claude 自己的功能。你和 Claude 的对话按 Claude（Anthropic）自己的隐私政策处理，请以官方隐私政策为准。建议只发写论文需要的材料，不要贴姓名、学号、账号等无关的私人信息。

## ⚠️ 提醒

- **学校和课程对 AI 协助写作有没有规定，请你自己确认。**
- **Claude 起草的段落，请改成自己的话，并自己通读几遍。** 用高效节奏时 AI 起草得更多，这一条更重要。
- 关键文献（支撑主要论点和数据的那几篇）请自己点开核对一次，AI 也会出错。
